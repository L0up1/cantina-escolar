# Requisitos Funcionais

## RF01
O sistema deve permitir o cadastro de alunos.

## RF02
O sistema deve permitir editar os dados de um aluno.

## RF03
O sistema deve permitir cadastrar produtos.

## RF04
O sistema deve permitir editar produtos.

## RF05
O sistema deve permitir inativar produtos.

## RF06
O sistema deve permitir registrar uma venda.

## RF07
O sistema deve permitir consultar o histórico de compras de um aluno.

## RF08
O sistema deve gerar um relatório mensal por aluno.

## RF09
O sistema deve registrar pagamentos.

## RF10
O sistema deve permitir autenticação de usuários.
